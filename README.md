# لوحة تحكم لين بيزنس سوليشنز

لوحة تحكم محلية بتشتغل على جهازك، والموقع بيقرا المحتوى من Supabase وهو شغّال.

**مفيش خطوة نشر.** تحفظ في اللوحة → يظهر على الموقع خلال ٣٠ ثانية على الأكثر.

```
تعدّل هنا  →  Supabase  →  الموقع بيقراها وهو بيرسم الصفحة
```

السيرفر بتاع الموقع هو اللي بيجيب المحتوى ويرسم الصفحة كاملة، فجوجل بيشوف كل
النصوص عادي زي ما كان بالظبط.

---

## التجهيز — مرة واحدة بس

### ١. اعمل مشروع Supabase

من [supabase.com](https://supabase.com) اعمل مشروع جديد.

### ٢. اعمل الجداول

من لوحة Supabase: **SQL Editor → New query**، الصق محتوى الملف
`Lean-Solutions/supabase/schema.sql` كله واضغط Run.

### ٣. اعمل حساب الأدمن

- **Authentication → Users → Add user**: اكتب بريدك وكلمة مرور، وفعّل
  *Auto Confirm User*.
- بعدها في **SQL Editor** شغّل ده وحط بريدك مكان اللي في المثال:

  ```sql
  insert into public.admins (user_id, email)
  select id, email from auth.users where email = 'you@example.com'
  on conflict (user_id) do nothing;
  ```

  الخطوة دي مهمة: مجرد إن الحساب موجود مش كفاية — لازم يكون في جدول `admins`.

### ٤. حط المفاتيح

المفاتيح في **Project Settings → API**. محتاج مفتاح `anon` بس — مفتاح
`service_role` مش مستخدم في أي مكان.

المكانين دول، ونفس القيم في الاتنين:

- `lean-admin/src/environments/environment.ts`
- `Lean-Solutions/src/environments/environment.ts`

```ts
export const environment = {
  production: true,
  supabase: {
    url: 'https://xxxx.supabase.co',
    anonKey: '<مفتاح anon / public>',
  },
};
```

> مفتاح `anon` آمن إنه يكون مكتوب هنا — الحماية كلها على مستوى قاعدة البيانات
> (RLS). في الموقع هو أصلاً مابيوصلش للمتصفح: السيرفر بيقرا وبيرسم الصفحة
> وبيبعت المحتوى جاهز.

الدومينات اللي الموقع بيردّ عليها مكتوبة في
`Lean-Solutions/angular.json` تحت `security.allowedHosts` — لازم تضيف دومينك
هناك قبل الرفع.

### ٥. حمّل المحتوى الحالي

اتعمل خلاص — قاعدة البيانات فيها الـ٢٢ خدمة والـ١٢ مشروع والـ١٦ قسم نصوص.

النسخة الأصلية من المحتوى محفوظة في `lean-admin/public/seed.json` كنسخة احتياطية.
لو احتجت ترجّعها يومًا ما، قوللي.

## التشغيل اليومي

```bash
cd lean-admin
npm start
```

بيفتح اللوحة على <http://localhost:4300> وبتلاقي الخدمات قدامك على طول. عدّل
واحفظ — وخلاص، مفيش خطوة تانية.

---

## اللي تقدر تعدّله

| القسم | فيه إيه |
| --- | --- |
| **الخدمات** | الـ٢٢ خدمة: الكرت وصفحة التفاصيل، الترتيب، الإخفاء، الحذف والإضافة |
| **المشاريع** | الـ١٢ مشروع بنفس الشكل |
| **نصوص الموقع** | الهيدر، الفوتر، السلايدر، كل أقسام الرئيسية، والصفحات الداخلية — بالعربي والإنجليزي، ومعاها بيانات السيو |
| **بيانات الشركة** | الاسم، الهاتف، البريد، المدينة، لينكدإن، اللوجو، الدومين، والخريطة |
| **الملفات والصور** | رفع صور وأيقونات وملفات Lottie جديدة |

كل نص ليه خانتين: عربي وإنجليزي، جنب بعض.

## تشغيل الموقع

الموقع بقى محتاج **استضافة بتشغّل Node** — مش مجرد رفع ملفات، لأنه بيقرا من
Supabase وهو بيرسم الصفحة.

```bash
cd Lean-Solutions
npm run build
npm run serve        # على http://localhost:4000
```

على الاستضافة: ارفع مجلد `dist/lean-solutions` كله وشغّل
`node dist/lean-solutions/server/server.mjs`. أهم حاجة: الدومين بتاعك لازم يكون
مكتوب في `angular.json` تحت `security.allowedHosts` قبل ما تبني، وإلا السيرفر
هيرفض كل الطلبات.

---

## لو حاجة وقفت

**«محتاج صلاحية أدمن عشان تحفظ»** — الحساب مش في جدول `admins`. ارجع لخطوة ٣.

**الموقع بيقول «مش قادر يحمّل محتواه»** — يا إما بيانات Supabase ناقصة في
`Lean-Solutions/src/environments/environment.ts`، يا إما قاعدة البيانات فاضية.

**الموقع بيردّ 400 وبيقول Host is not allowed** — الدومين مش مكتوب في
`angular.json` تحت `security.allowedHosts`.

**عدّلت وماظهرش على الموقع** — السيرفر بيحتفظ بالمحتوى ٣٠ ثانية. استنى شوية
وحدّث الصفحة. تقدر تغيّر المدة من `CONTENT_TTL_MS`، أو تخليها فورية بـ
`curl -X POST <دومين الموقع>/api/revalidate`.

## إزاي بيشتغل

- سيرفر الموقع بيقرا الجداول من Supabase قبل ما يرسم أي صفحة، وبيحتفظ بالنتيجة
  ٣٠ ثانية عشان مايضربش على قاعدة البيانات في كل طلب.
- المتصفح بياخد نسخة واحدة من المحتوى من `/api/content` بتاع الموقع نفسه —
  مش من Supabase — ومتخزّنة في الكاش، فالتنقل بين الصفحات مايحتاجش أي طلب تاني.
- شكل المحتوى معرّف في `Lean-Solutions/src/app/core/content.ts` و`catalog.ts`.
  لو ضفت حقل هناك، ضيفه كمان في `lean-admin/src/app/core/schema.ts` عشان يظهر
  في اللوحة.
- الفورمات كلها مبنية من `schema.ts` — مفيش فورم مكتوبة بالإيد لكل قسم.
- `sitemap.xml` بيتولّد من قاعدة البيانات وقت الطلب، فأي خدمة جديدة بتدخل فيه
  لوحدها.
